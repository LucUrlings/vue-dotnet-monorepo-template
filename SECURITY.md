# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues, discussions,
or pull requests.

Use the repository's **Security** tab and select **Report a vulnerability** to
open a private security advisory. If private vulnerability reporting is not
enabled, contact the maintainers through a private channel listed on their
GitHub profiles rather than opening a public issue.

Include the affected version, reproduction details, impact, and any suggested
mitigation. Maintainers should acknowledge reports promptly and coordinate a
responsible disclosure timeline with the reporter.

Only supported versions on the repository's default branch receive security
updates unless a maintainer states otherwise.
